Worked Example: Female 5xFAD Time Course with Centroid-Based Trajectory Collapse

Saren M. Springer

2026-07-13

Overview

This vignette documents a complete WATER analysis of female wildtype samples from a 5xFAD aging dataset. The example contains four ages—4, 8, 12, and 18 months—with three biological replicates per age. WATER was run using its default centroid-based method for collapsing related clusters into trajectories.

The purpose of this vignette is to show:

  1. how to organize the input data;
  2. how to launch a complete WATER run;
  3. which interactive decisions were made during clustering and refinement;
  4. how to interpret the audit and stability outputs; and
  5. where the final results are saved.

This is a workflow example rather than a biological interpretation of the dataset.

Dataset structure

The expression matrix contained 55,351 input features and 12 samples. Samples were ordered by age, with three replicates at each timepoint.

WATER timepoint Biological age Replicates Sample names
T1 4 months 3 WT1_F_4M, WT2_F_4M, WT3_F_4M
T2 8 months 3 WT1_F_8M, WT2_F_8M, WT3_F_8M
T3 12 months 3 WT1_F_12M, WT2_F_12M, WT3_F_12M
T4 18 months 3 WT1_F_18M, WT2_F_18M, WT3_F_18M

Two input tables were used:

  • an expression matrix, with feature identifiers in the first column and samples in the remaining columns;
  • a log2 fold-change matrix aligned to the same feature identifiers.

A feature list was also supplied through feature_list = "filter.txt".

Load WATER and the input files

During package development, the WATER runner can be sourced directly.

data <- read.csv("WT_female_Alz_exp_data.csv")
log2fc <- read.csv("WT_female_Alz_log2fc_data.csv")

source("Running_WATER.R")

Run WATER

The complete analysis was launched with run_water().

water <- run_water(
  data = data,
  replicates = list(
    T1 = 3,
    T2 = 3,
    T3 = 3,
    T4 = 3
  ),
  log2fc = log2fc,
  preprocess_params = list(
    modality = "RNA",
    output_dir = "WT_female_Alz",
    save_outputs = TRUE,
    tpm_threshold = 1.0,
    feature_list = "filter.txt"
  )
)

The output directory used in this example was:

WT_female_Alz/

WATER created stage-specific subdirectories containing tables, R objects, and plots.

Initial clustering and trajectory labeling

WATER evaluated candidate cluster numbers from k = 2 through k = 30 using silhouette analysis and generated heatmaps for candidate solutions.

Centroid-based trajectory collapse

At the trajectory-labeling prompt, the default centroid method was selected:

Centroid clustering, r_threshold = 0.8

WATER compared the mean z-scored expression profile of each cluster and grouped clusters whose centroid profiles met the correlation threshold. At r = 0.8, the eight initial clusters remained as eight distinct trajectories in this dataset.

WATER then wrote a rename template:

label_classic/tables/trajectory_rename_template.csv

The Biological_label column was completed manually, and the edited file was supplied back to WATER. The initial eight trajectories were:

Initial audit

WATER next evaluated assignment stability using leave-one-out analysis and a correlation-based audit.

Initial leave-one-out analysis

Each of the 12 samples was removed once, and the clustering solution was reevaluated.

Initial correlation audit

Each feature was compared with the centroid of its assigned trajectory and with competing trajectories.

Audit decision Features Percent
Keep original 1,533 77.4%
Reassigned 210 10.6%
Weak 88 4.4%
Ambiguous 149 7.5%

The weak and ambiguous feature sets were carried into dedicated refinement steps rather than being discarded.

Refinement of ambiguous features

The 149 ambiguous features were reclustered independently. WATER recommended:

k = 2, 4, 7

For this run, k = 4 was selected. The default centroid-based collapse method was again used with r_threshold = 0.8. All four ambiguous clusters remained distinct before biological renaming.

objects/   Serialized R objects in .rds format
plots/     Diagnostic or final visualizations
